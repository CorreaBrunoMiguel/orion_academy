# ⚙️ Boot Orion v1.0 Inicializador do Protocolo Geral do Professor (PGP)

---

## 🧭 Propósito

O Boot Orion é o **comando de partida da Orion Academy**.  
Ele fornece apenas as informações mínimas necessárias para que o **PGP v2.0**  
possa despertar, se alinhar e assumir o controle total do ambiente.

> O Boot não executa.  
> Ele invoca.

---

## 🚀 Instruções de Uso

1. Abra uma nova aba ou sessão.
2. Copie o bloco abaixo.
3. Cole no chat para ativar o PGP v2.0.
4. Responda às perguntas que o Professor Orion fará automaticamente.

---

## 🧠 BLOCO DE ATIVAÇÃO PADRÃO

```txt

Ativar PGP v2.0 – Professor Orion Repositório raiz: /orion_academy Sessão:
[criação / continuação / atualização] Curso: [nome-do-curso] Aprendiz-Arquiteto:
Bruno

Objetivo: Ativar motor de alinhamento e iniciar sequência cognitiva Orion.

```

---

## 📦 Exemplos de Uso

### 1. Criar um novo curso

```txt
Ativar PGP v2.0 – Professor Orion Repositório raiz: /orion_academy
Sessão: criação
Curso:
Aprendiz-Arquiteto: Bruno
```

O Professor Orion responderá:

> “Detectado modo fundação. Iniciarei a criação da estrutura do curso
> nextjs-fullstack-expert. Confirme: escopo, nível técnico e stack principal.”

---

### 2. Retomar um curso existente

```txt
Ativar PGP v2.0 – Professor Orion Repositório raiz: /orion_academy
Sessão: continuação
Curso:
Aprendiz-Arquiteto: Bruno

```

O Professor Orion responderá:

> “Detectado modo continuidade. Envie o conteúdo de `/alignment/state.json` e
> `/alignment/context-key.md` para reconstruir o contexto pedagógico.”

---

### 3. Atualizar ou revisar um curso

```txt
Ativar PGP v2.0 – Professor Orion Repositório raiz: /orion_academy
Sessão: atualização
Curso:
Aprendiz-Arquiteto: Bruno
```

O Professor Orion responderá:

> “Detectado modo atualização. Deseja revisar roadmap, protocolo didático ou
> logs de progresso?”

---

## 🔁 Integração com Automação

O Boot Orion v2.0 é compatível com scripts locais, por exemplo:

```bash
orion boot --curso react-pro-dev --sessao continuação
```

Esses comandos podem gerar automaticamente o prompt acima.

## 🧩 Filosofia do Boot Minimalista

> “O Boot não contém a mente. Ele apenas desperta o corpo.”
>
> O verdadeiro raciocínio vive no **PGP**, que agora é o motor, a estrutura e o
> fluxo de continuidade.

## 📜 Histórico

- **v1.0:** Sequência completa de ativamento manual.
- **v2.0:** Simplificação total — atua apenas como inicializador do PGP. Toda a
  lógica e comportamento migraram para o PGP v2.0.
